## The complete list

The tables above are curated: they cover the direct dependencies declared in
`pubspec.yaml`, the embedded works that are not Dart packages (the font, the
flag drawings) and the transitive dependencies large enough to be worth naming.

The exhaustive list, with the full text of every licence, is generated by
Flutter itself from `LicenseRegistry` and is reachable in the app under
**About → Full licences**. Flutter registers the `LICENSE` file of every
package in the dependency graph automatically; `registerThirdPartyLicenses()`
in `lib/util/third_party_licenses.dart` adds the two works Flutter cannot see
on its own — the Roboto font bundled under `fonts/` (its `LICENSE.txt` ships as
an asset) and the flag-icons drawings.

## Keeping this up to date

When a dependency is added to `pubspec.yaml`, add it to
`lib/util/third_party_credits.dart` as well. `test/view/about_page_test.dart`
asserts that every direct dependency is credited, so an omission fails the test
suite rather than shipping silently. If the new dependency embeds third-party
assets whose licence its own `LICENSE` file does not cover — as `flag` does —
register that licence in `lib/util/third_party_licenses.dart` too.
